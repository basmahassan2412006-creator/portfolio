# Basma Hassan Fathy — Portfolio Website

A responsive, single-page portfolio built with HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — content and page structure.
- `style.css` — layout, colors, responsive styling, and visual components.
- `script.js` — mobile navigation and automatic footer year.
- `DOCUMENTATION.pdf` — project documentation and setup instructions.

## Run locally
1. Extract the ZIP file.
2. Open the `Basma_Portfolio_Website` folder.
3. Double-click `index.html`, or open the folder in Visual Studio Code and use the Live Server extension.
4. An internet connection is only needed to load the optional Google Fonts; the rest of the website is local.

## Customize
- Update personal details and project descriptions in `index.html`.
- Change colors and spacing in `style.css` under `:root`.
- Update email, GitHub, and LinkedIn links in the Contact section.
- Add real project demo/repository links when available.
